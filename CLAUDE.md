# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

EchoCV: AI interview coach for Indonesian IT students. Scores answer *delivery* (eye contact, smile, posture, fillers, pace, pauses, voice) and *content* (STAR, relevance) in Indonesian or English. Being built into a fullstack app (Next.js frontend + API, Python speech backend) around ML models that already exist in `ml/`.

Design source of truth: `docs/superpowers/specs/2026-10-06-echocv-architecture-design.md` (workflow diagrams, target folder layout, open decisions in section 5). Model results: `docs/model-report-v0.md`.

## Commands

Root (pnpm 11 workspace, Node 22+):
```bash
pnpm install
pnpm dev:web                                   # http://localhost:3000
pnpm lint | pnpm test | pnpm build             # all proxy to --filter web
pnpm --filter web typecheck                    # next typegen && tsc --noEmit
pnpm --filter web exec vitest run tests/unit/rubric.test.ts -t "sum to 1"   # single test
pnpm --filter web test:e2e                     # Playwright, auto-starts pnpm dev
pnpm --filter web exec playwright test tests/e2e/smoke.spec.ts
```

Python projects (uv, Python 3.12 pinned; never 3.13+). Each is a separate uv project, run from its own dir:
```bash
cd services/speech && uv sync && uv run uvicorn app.main:app --reload   # :8000/health
uv run pytest tests/test_schemas.py::test_pydantic_fields_match_shared_schema
uv run ruff check && uv run ruff format --check
uv sync --group ml        # heavy stack (faster-whisper, silero-vad, librosa, mediapipe); not in CI

cd ml && uv sync && uv run pytest && uv run ruff check   # CUDA torch on non-mac
cd ml/calibration && uv run pytest                       # separate project: mediapipe's OpenCV clashes with ultralytics'
```
ML pipeline run order (downloads, YOLO, Whisper, calibration, report): see `ml/README.md`. Run GPU jobs one at a time (4 GB RTX 3050 Ti).

CI (`.github/workflows/ci.yml`): web = lint, test, build; speech = `uv sync --frozen`, ruff check, ruff format --check, pytest, docker build. `ml/` is not in CI.

## Architecture

Three runtimes joined by JSON contracts in `shared/`:

- **`apps/web`** (Next.js 16 App Router, React 19, Tailwind 4, shadcn/ui on `@base-ui/react`). Pages: `(marketing)`, `practice` (live mode), `upload`, `report/[id]`, `dashboard`. API routes `api/sessions`, `api/uploads`, `api/reports` are 501 stubs. `lib/vision`, `lib/audio`, `lib/scoring`, `lib/llm` are empty placeholders. Read `apps/web/AGENTS.md`: this Next.js version differs from training data; check `node_modules/next/dist/docs/` before writing Next code.
- **`services/speech`** (FastAPI). `/health` works; `/analyze` is a 501 stub. Planned: Silero VAD -> fine-tuned faster-whisper -> fillers/rate, librosa prosody, plus upload-mode vision (ffmpeg frames -> MediaPipe + YOLO).
- **`ml/`** trains the models: `yolo/` (4-class behaviour detector, YOLO26n), `whisper/` (LoRA on whisper-large-v3-turbo keeping fillers as tokens, converted to CTranslate2 int8), `calibration/` (eye-contact/smile thresholds), `eval/` (rubric weights vs HR ratings, not built). `common/provenance.py` writes `datasets.json` beside every model.
- **`shared/`** (`@echocv/shared`): `rubric.json` (8 dimensions, weights must sum to 1, currently placeholder equal weights), `labels.json` (behaviour classes, filler tokens `[EEE] [HMM] [UM]`), `thresholds.json` (generated by `ml/calibration/calib/export_thresholds.py`, do not hand-edit), `schemas/*.schema.json`.

Data flow: live mode runs vision in the browser and sends only metrics JSON + audio (video never leaves the laptop). Upload mode runs everything server-side. `api/reports` merges visual + speech metrics, calls the LLM for content, applies the rubric. DB/auth/storage provider is undecided (Supabase recommended); no Prisma schema yet.

## Contracts and gotchas

- `services/speech/app/schemas.py` mirrors `shared/schemas/speech-metrics.schema.json` (snake_case in Python, camelCase on the wire via alias generator, `extra="forbid"`). `tests/test_schemas.py` fails on drift; change both together.
- `apps/web/tests/unit/rubric.test.ts` pins rubric weight sum and the exact 4 behaviour classes; changing `labels.json` means retraining YOLO (`ml/yolo/class_map.yaml`).
- faster-whisper must be called with `suppress_tokens` from the shipped `suppress_tokens.json`, not the default `[-1]`, or it never emits filler tokens.
- Weights, datasets, recordings, `.env` are git-ignored; weights live on Hugging Face Hub. `apps/web/public/models/` is ignored (models pulled from HF). Env template: `.env.example` -> `apps/web/.env.local`.
- Training data must be commercially safe; Columbia Gaze / MPIIFaceGaze are only for measuring eye-contact constants.
- Ultralytics YOLO is AGPL-3.0 (repo must stay public, or swap before a commercial launch).
- Docker is not used locally; the speech Dockerfile is deploy-only and built in CI.
